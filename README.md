# 😂 Joke API Web App

A simple random joke generator built with Node.js, Express.js, EJS, Axios, and CSS. The application fetches random jokes from the JokeAPI and displays them on a clean, responsive web page.

## Features

 - Fetches random jokes from the JokeAPI.

 - Supports single jokes and two-part jokes (setup and delivery).

 - Displays jokes using EJS templates.

 - Responsive user interface styled with CSS.

 - Uses Axios to make HTTP requests to an external API.

## Technologies Used

 - Node.js — JavaScript runtime.

 - Express.js — Web application framework.

 - EJS — Renders dynamic HTML pages.

 - Axios — Fetches data from the JokeAPI.

 - HTML and CSS — Page structure and styling.

 - JokeAPI — Provides random jokes.

## Getting Started

### Prerequisites

Install Node.js and npm on your computer.

### Installation

1. Clone this repository:

git clone https://github.com/mukultekwani/Random-Joke-Generator.git

2. Navigate to the project directory:

cd Random-Joke-Generator

3. Install the required dependencies:

npm install

### Running the Application

Start the server:

nodemon index.js

Open your browser and visit:

http://localhost:3000

The application will fetch a random joke and display it on the page. Refresh the page to request another joke.
